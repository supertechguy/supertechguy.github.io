UtahSAINT Radio Network

An encrypted, members-only DMR radio network (WQWK474) for UtahSAINT members — FCC Part 90 licensed, AES-256 encrypted, simplex radio-to-radio with no repeaters, gateways, or internet links. I manage the network, its licensing, and member radio programming.

NetDash

A network security dashboard featuring full packet capture and analysis — flow-style visibility similar to flow-tools, built from packet capture instead of flow export.

SourceForge

netlog

A terminal network log viewer for sysadmins and network engineers: smart color highlighting, MAC vendor and GeoIP lookup, deny/allow event glyphs, follow mode, and a full interactive TUI that handles huge and gzipped logs — pure Python standard library.

GitHub

iprep

A command-line IP reputation aggregator. Queries 25+ threat-intel and context sources in parallel — VirusTotal, AbuseIPDB, Shodan, Spamhaus, GreyNoise, and more — and returns a single risk verdict with the detail behind it.
